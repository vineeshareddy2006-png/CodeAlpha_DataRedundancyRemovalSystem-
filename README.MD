# Data Redundancy Removal System

## Project Description
This project helps prevent duplicate data entries using Python and SQLite.

## Features
- Stores data in an SQLite database.
- Checks email addresses before inserting records.
- Prevents duplicate email entries.
- Displays stored records.

## Technologies Used
- Python
- SQLite
- Google Colab

## How It Works
The system checks whether an email address already exists in the database. If it exists, the system rejects the duplicate entry. Otherwise, it stores the new record.

## Learning Outcome
Learned basic database operations and duplicate data prevention.
